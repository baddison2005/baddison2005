### Application Development:
- **Window Layouts for macOS and KDE Plasma:** I have recently expanded into open source application development with **Window Layouts**, a pair of desktop utilities for quickly arranging and managing application windows using predefined or fully customizable layouts. [Window Layouts for macOS](https://github.com/baddison2005/window-layouts-macos) is a native macOS application featuring custom layouts, global keyboard shortcuts, multi-display support, and optional visual drag-and-drop layout controls. [Window Layouts for KDE Plasma](https://github.com/baddison2005/window-layouts-kde) brings similar functionality to KDE Plasma 6 on Wayland, including custom layouts, window and workspace management, keyboard shortcuts, and integration with the Plasma desktop. Custom layouts can also be shared between the macOS and KDE versions.
- **OLED Window Guard for macOS:** I developed [**OLED Window Guard**](https://github.com/baddison2005/oled-window-guard), a native macOS menu-bar application designed to help reduce the risk of OLED burn-in from static application windows. The app periodically repositions eligible windows using configurable movement modes, including randomized position shifts, coordinated window swaps, and integration with my **Window Layouts for macOS** layouts. It includes multi-display support, per-display settings, activity-aware safety checks, movement previews and restoration, application exclusions, and optional window and display dimming. OLED Window Guard is built with SwiftUI, AppKit, Accessibility APIs, and Core Graphics, without requiring screen recording, telemetry, or private macOS APIs.

  These applications were developed with substantial assistance from **OpenAI's Codex**. I directed the application design, requirements, testing, and releases, while Codex assisted with code implementation, debugging, documentation, and packaging.
